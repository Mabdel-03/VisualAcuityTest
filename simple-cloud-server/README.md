# Optional CSV Upload Servers

## Purpose

This directory contains optional Flask services for receiving CSV files generated by the Visual Acuity Test iOS application. The iOS app exports manually by default. These services are only needed when a study deployment has an approved server endpoint and the app is configured with `CloudUploadURL`.

## Services

- `app.py`: Stores validated CSV uploads locally and optionally emails a CSV attachment when email is enabled.
- `google_drive_uploader.py`: Stores validated CSV uploads locally and uploads them to a configured Google Drive folder.

Both services expose `POST /upload` and `GET /health`. The email server also exposes `GET /files`.

## Request Format

```json
{
  "filename": "example.csv",
  "content": "Letter_Displayed,Transcribed_Text,Mapped_Result\nC,see,C\n",
  "timestamp": "2026-07-08T00:00:00Z",
  "source": "visual_acuity_ios_app"
}
```

The server requires JSON input, rejects filenames with path components, accepts only `.csv` filenames, and stores files under `uploaded_csvs` unless `UPLOAD_FOLDER` is configured.

## Local Setup

```bash
cd simple-cloud-server
python3 -m venv venv
source venv/bin/activate
pip install -r requirements_google.txt
```

Run the email-capable local storage service:

```bash
python app.py
```

Run the Google Drive service:

```bash
python google_drive_uploader.py
```

## Configuration

Common environment variables:

```text
HOST=0.0.0.0
PORT=5000
DEBUG=false
UPLOAD_FOLDER=uploaded_csvs
MAX_FILE_SIZE_MB=10
```

Email service variables:

```text
EMAIL_ENABLED=false
SMTP_SERVER=smtp.gmail.com
SMTP_PORT=587
SENDER_EMAIL=
SENDER_PASSWORD=
RECIPIENT_EMAIL=mabdel03@mit.edu
```

Google Drive service variables:

```text
GOOGLE_DRIVE_FOLDER_ID=1gQNIG23hqthx7XncvycEDuJPaf8yV012
GOOGLE_CREDENTIALS_FILE=credentials.json
GOOGLE_TOKEN_FILE=token.pickle
```

Do not commit `.env`, `credentials.json`, `token.pickle`, uploaded CSV files, or logs.

## iOS Configuration

Manual export is the default. To enable server upload for the training data collection workflow, set `CloudUploadURL` in the app bundle to a deployed endpoint such as:

```text
https://example-study-server.org/upload
```

Do not use `http://localhost:5000/upload` for a physical iOS device unless the server is reachable from the device through an appropriate network configuration.

## Tests

Run the local server tests from this directory:

```bash
python -m unittest test_app.py
```

The tests cover health checks, invalid content types, missing fields, filename traversal rejection, and successful CSV upload with email mocked.

## Deployment Notes

Use a production WSGI server such as Gunicorn for hosted deployments:

```bash
gunicorn app:app
```

For Google Drive deployments, complete OAuth setup in the deployment environment before accepting study data. Confirm that storage location, retention, access control, and backup practices match the study protocol.
